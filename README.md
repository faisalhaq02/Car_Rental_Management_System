## Overview

This project implements a **Car Rental Management System** using a relational database model. It demonstrates database design principles, normalization, integrity constraints, and SQL-based business reporting for managing customers, vehicles, reservations, payments, and maintenance records.

The system is designed to maintain data consistency, enforce referential integrity, and support business operations through analytical SQL queries.

## Database Design

The database consists of multiple interconnected entities including:

- Customer
- Customer Contact
- Dealer
- Car
- Reservation
- Payment
- Maintenance
- Employee
- Reservation-Car Mapping

Relationships are enforced using foreign keys with cascading operations where appropriate to maintain referential integrity.

## Database Features

### Schema Design

- Relational database modeling
- Entity relationships
- Auto-increment primary keys
- Normalized tables
- Optimized data organization

### Integrity Constraints

The database enforces several integrity rules including:

- Primary Keys
- Foreign Keys
- UNIQUE Constraints
- NOT NULL Constraints
- CHECK Constraints
- Cascading Deletes

Constraint validation scripts are included to verify database correctness.
